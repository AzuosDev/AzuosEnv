# SPEC resumida
Hierarquia: Workspace > Space > Folder (> Subfolder) > List > Task > Subtask; Checklist dentro da tarefa. Tarefa pode estar em várias Lists.
Papéis: owner > admin > member > limited > guest. Private + permissões por objeto: view, comment, edit, full.
Statuses por Space/Folder/List com grupos notStarted, active, done, closed.
Statuses padrão Dev Azuos: Backlog, A fazer, Em andamento, Code review, Teste, Homologação cliente, Deploy, Concluído, Bloqueado.
Comercial: Lead, Reunião, Proposta enviada, Negociação, Fechado, Perdido.
Spaces iniciais: Clientes, Produtos, Comercial, Interno.
Fase 1: auth, workspaces, hierarquia, tarefas, comentários, anexos, views, inbox, busca.
Fase 2: campos personalizados, dependências, time tracking, timesheets, dashboards, automações, templates.
Fase 3: docs, chat, planner, metas, formulários, workload, sprints.
Fase 4: IA Grok, whiteboards, integrações, API pública.
